# SŁOWARIUM — REFERENCE-QUALITY bar

**Not MVP.** This bar is intentionally brutal. Meeting it means an East-Slavic adult in Poland can trust the product for a real first week of life-in-Polish practice. Wave 1 foundations do **not** claim this bar is met.

## Criteria

### 1. Session-1 life loop without staff

A new invitee (learner + previewer for closed beta) can, alone, in one sitting: accept invite → onboard → open a module → complete a lesson with dialogue + practice → see honest feedback → leave knowing what to do tomorrow. No author/reviewer/admin roles required. No empty school.

### 2. Feedback that teaches

Wrong answers show **incorrect** explanation plus L1-appropriate note (`ukr` / `rus` / `bel`). Correct answers show **correct**. Dialogue and grammar are usable structures (turns, key lines, pan/pani, form/use/examples) — not dead `pre-wrap` theory walls.

### 3. Listening + speaking path

Listening is present in the learning path (audio or explicit interim listening contract). Speaking has a defined v1 path even if constrained (e.g. read-aloud / record later / shadow dialogue) — not “coming soon” forever with zero design.

### 4. Human-readable progress

Learner UI never leads with curriculum IDs (`GR-CAS-NOM-01`). Progress, review, and Kronika use human titles and outcome language (what you can do / what to repeat). Habit clarity: next action is obvious.

### 5. Zero civilian ops jargon

No DRAFT / JPJO / previewer / author / reviewer / mastery-ops language in learner chrome — except a **short, honest** preview banner when content is not independently certified. Banner ≠ staff vocabulary dump.

### 6. BEL is first-class L1

Belarusian L1 is equal to UKR/RUS in product language. UI may share a locale (e.g. RU menu), but copy must never frame BEL as optional, secondary, or “supported somehow.” Notes and onboarding treat bel with respect.

### 7. Content honesty contract

Either a human-reviewed PUBLISHED path **or** an explicit closed-beta preview contract (invitees learn on DRAFT with banner). No bait-and-switch empty catalog for people who were invited. Never fake PUBLISHED without JPJO.

### 8. Deploy teaches someone

Documented path to live HTTPS. Production env example and runbook let a competent engineer bring up private beta without tribal knowledge. Health/ready, invites, rollback are written down.

### 9. Admin weight ≤ learner craft

Heuristic: time/attention spent on admin/ops chrome must not exceed learner craft (lesson player, feedback, progress, copy). If admin grows faster than learning quality, fail this bar.

### 10. Competitive first week

For an East-Slavic adult in Poland, first-week experience beats a Telegram phrasebot: scenarios, register (pan/pani), incorrect+L1 feedback, progress you can narrate to a friend — not a dump of disconnected phrases.

## How to use this document

- Wave work ships foundations toward this bar.
- Never mark “reference quality achieved” until a critical audit against **all ten** passes.
- Prefer brutal honesty in `improvement-loop-status.md` over marketing language.
