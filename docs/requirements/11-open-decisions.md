## Блокирующие решения владельца (максимум три)

Без ответов на эти три нельзя утвердить операционно-критичные части пакета. Остальное покрыто рабочими решениями.

### DEC-016 — Операционная модель независимого методиста

- **Вопрос:** Кто в первые 12 месяцев обеспечивает независимое linguistic/methodological review (контракт, партнёр, ротация), если принцип «без self-approve» остаётся обязательным?
- **Почему важно:** CNT-020 / BUS-005; иначе публикация незаконна по собственным правилам.
- **Варианты:** основатель-автор + платный reviewer; внешняя редакция; временное ослабление CNT-020 (высокий риск).
- **Рекомендация:** платный независимый reviewer; self-approve не допускается.
- **Статус:** Open — **блокирующий**

### DEC-002 — Итоговая оценка письма и речи в exam-mode

- **Вопрос:** Кто ставит итоговый балл письма/речи для exam-mode и productive mastery?
- **Почему важно:** Достоверность B1/B2 тренировки vs 15 ч/нед.
- **Варианты:** (1) человек по рубрике; (2) портфолио без pass; (3) модель + обязательный human audit для pass.
- **Рекомендация:** (1) или временно (2) до появления оценщика; (3) alone запрещён (`ASM-010`).
- **Статус:** Open — **блокирующий** для V4 productive pass

### DEC-001 — Коммерческая граница (утверждение)

- **Вопрос:** Какая граница бесплатного/платного утверждается (не только working assumption)?
- **Почему важно:** FUN-200; paywall на placement опасен.
- **Варианты:** freemium с бесплатным placement; всё бесплатно временно; всё платно сразу.
- **Рекомендация:** freemium; placement бесплатен.
- **Статус:** Open для **утверждения**; working assumption уже в FUN-200 — **блокирует коммерческий запуск**, не учебную модель V1
