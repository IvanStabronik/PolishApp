## Блокирующие решения владельца (максимум три)

Остаются операционно критичными для запуска/публикации. Учебная модель Phase 2 не блокируется.

### DEC-016 — Операционная модель независимого методиста JPJO

- **Вопрос:** Кто в первые 12 месяцев обеспечивает независимое linguistic/methodological review (контракт, партнёр, ротация), если принцип «без self-approve» остаётся обязательным?
- **Почему важно:** CNT-020 / BUS-005; иначе публикация незаконна по собственным правилам.
- **Варианты:** основатель-автор + платный reviewer; внешняя редакция; временное ослабление CNT-020 (высокий риск).
- **Рекомендация:** платный независимый reviewer JPJO; self-approve не допускается.
- **Статус:** Open — **блокирующий** для публикации контента

### DEC-007 — Контролёр GDPR

- **Вопрос:** Кто юридический контролёр персональных данных при публичном запуске?
- **Почему важно:** SEC-001; платежи и любые персональные данные.
- **Статус:** Open — блокирует публичный сбор платежей/голоса

### DEC-008 / DEC-013 — Имя продукта и юрист для правовой справки B1

- **Вопрос:** Финальное имя продукта; нужна ли платная юрконсультация перед публикацией справки о правовых эффектах B1?
- **Статус:** Deferred / Open перед публикацией маркетинга и правовой справки

## Закрытые / суженные решением Phase 2 (не блокируют учебную архитектуру)

### DEC-002 — Итоговая оценка письма и речи

- **Working lock Phase 2:** подтверждённая оценка письма/речи — **человек**, отдельная **платная** функция. AI только formative.
- **Статус:** Assumed (locked for now); детали SLA/рубрик — Later / V4 design

### DEC-001 — Коммерческая граница

- **Working lock Phase 2:** placement + первый модуль бесплатны; полная траектория и exam-mode платны; **конкретные цены не задаются**.
- **Статус:** Assumed (locked for now); утверждение цифр тарифа — позже
