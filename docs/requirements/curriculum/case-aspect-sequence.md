# Последовательность введения падежей и аспекта

**Статус:** Phase 2 draft — не утверждено (`PED-015`, `CNT-016`, документ 10 §10.8).  
**Язык документа:** русский; примеры — нормативный польский.  
**Связанный инвентарь:** `grammar-inventory.md` (ID `GR-CAS-*`, `GR-ASP-*`).  
**Дата сверки источников:** 2026-09-05.

---

## 0. Принципы

1. Падеж вводится как **функция + форма + типичная rekcja**, а не как колонка окончаний (`PED-001`, `PED-002`).
2. Порядок — **компромисс** между коммуникативной необходимостью для первой аудитории (UKR/RUS/BEL), требованиями покрытия załącznik nr 1 и управляемой нагрузкой.
3. **Присутствие формы в input ≠ mastery.** Mastery задаётся evidence-типами инвентаря и `level-exit-criteria.md`.
4. Аспект ведётся **отдельным путём** (`PED-004`). Лексические пары на A1 не считаются освоением выбора.
5. **Запрещено утверждать**, что аспект «просто переносится» с украинского, русского или белорусского. Сходство систем создаёт ложную уверенность и устойчивые fossilized errors.

## 1. Выбранная последовательность падежей (стадии)

Обозначения: **I** = введение (formulaic / receptive+guided); **P** = продуктивный контроль в ограниченных контекстах; **R** = повторное углубление.

| Стадия | Когда (ориентир уровня) | Падеж / узел | Режим | Ключевые ID |
|---|---|---|---|---|
| S0 | Старт A1 | Мета: «падеж = функция» | I | GR-CAS-FUNC-MAP-01 |
| S1 | Ранний A1 | **Mianownik** (подлежащее, *to* / Adj-предикатив) | I→P | GR-CAS-NOM-01, -02 |
| S2 | Ранний A1 | **Biernik** прямого объекта; одуш. м. упрощённо | I→P | GR-CAS-ACC-01 |
| S3 | Ранний–средний A1 | **Miejscownik** с *w/na/o* (место, тема) | I→P | GR-CAS-LOC-01 |
| S4 | Средний A1 | **Dopełniacz** с *do / u / z(из) / od / nie ma*; мера | I→P | GR-CAS-GEN-01, -02, -04 |
| S5 | Средний A1 | **Dopełniacz** после *nie* + объект; ядро rekcja (*słuchać*) | I→P | GR-CAS-GEN-03, -05 |
| S6 | Средний–поздний A1 | **Narzędnik** предикатива (*jest nauczycielem*) + орудие/транспорт | I→P | GR-CAS-INS-01, -02 |
| S7 | A1 (формулы) → A2 (P) | **Wołacz** обращений; связка с *pan/pani* | I (A1) → P (A2) | GR-CAS-VOC-01, GR-PRAG-PAN-01 |
| S8 | Поздний A1 / ранний A2 | **Biernik/Miejscownik** контраст *na/w* (направление vs место) | R | GR-CAS-ACC-02, GR-CAS-LOC-01 |
| S9 | A2 | **Celownik** (адресат, *podobać się*, *jest mi…*) | I→P | GR-CAS-DAT-01 |
| S10 | A2 | Полный контур 7 падежей + **męskoosobowy** во мн. | R+P | GR-MO-VIR-01 |
| S11 | B1 | Трудные парадигмы, liczebniki×падеж, относительные клаузы | R | GR-NUM-VIR-01, GR-SYN-REL-01 |
| S12 | B2 | Стилистика падежных оборотов, пассив/безличность (смежные) | R | GR-PASS-01, GR-IMPERS-* |

### Краткая формула порядка

**Nom → Acc (объект) → Loc (где) → Gen (куда *do* / нет / *nie*) → Instr (кем есть / чем) → Voc (обращение) → Dat (кому) → спираль всех семи.**

## 2. По стадиям: зачем здесь; что уже умеет; что отложено; L1-ошибки

### S0 — Метакарта падежей (старт A1)

- **Почему здесь:** Восточнославянский L1 приходит с иллюзией «падежи уже знаю». Нужен явный контракт: учим **польские функции**, не «повторяем школьную таблицу».
- **Уже умеет:** Опознать в L1 идею падежа; читать латиницу (входной фильтр продукта — вне этого документа).
- **Отложено:** Любые полные парадигмы; celownik; продуктивный wołacz; męskoosobowy.
- **Ожидаемые L1-ошибки:**
  - **UKR:** «У нас сім відмінків / кличний є» → пропуск польских отличий rekcja.
  - **RUS:** «Шесть падежей + сейчас выучим седьмой» → игнор функций *w/na*, Gen после *nie*.
  - **BEL:** Смешение школьных названий падежей с польскими ярлыками без функции.

### S1 — Mianownik

- **Почему здесь:** Нулевая точка коммуникации: назвать себя, объект, свойство (*To jest…*, *Jestem Anna* / позже Instr для роли).
- **Уже умеет:** S0; базовые N/Adj леммы урока.
- **Отложено:** Nom как единственный предикатив профессии (*\*jest nauczyciel*); подлежащее в Gen.
- **L1-ошибки:**
  - **UKR:** Верный Nom, но *\*Ja єсть…* / лишнее местоимение.
  - **RUS:** *\*Это есть…*; обязательное *я* в каждом предложении.
  - **BEL:** Кальки связки *ёсць*; род лемм (*problem*).

### S2 — Biernik (объект)

- **Почему здесь:** Сразу после Nom даёт транзитивные бытовые акты: *chcę kawę, kupuję chleb, widzę Annę*. Коммуникативно критично раньше «красивой» полной деклинации.
- **Уже умеет:** Nom субъекта; несколько транзитивов.
- **Отложено:** Полное правило żywotność во всех классах; Gen после отрицания (S5); сложные предлоги + B.
- **L1-ошибки:**
  - **UKR:** Одуш. м. частично ок; ж. *-ę* vs укр. *-у/-ю*.
  - **RUS:** *\*widzę student* / смешанные окончания; путаница одуш.
  - **BEL:** Как UKR + орфография носовых в B (*książkę*).

### S3 — Miejscownik (*w/na/o*)

- **Почему здесь:** Локация (*mieszkam w…*, *jestem na…*) и тема (*mówię o…*) — ежедневный быт; в zał. 1 A1 miejscownik уже в функциях.
- **Уже умеет:** Nom/Acc в простых фразах.
- **Отложено:** Полная таблица чередований; тонкий выбор *w/na* для всех топонимов; *po* + Msc в объёме B.
- **L1-ошибки:**
  - **UKR:** *\*w Polska*; *на Україні* → давление *na* там, где польск. *w Polsce*.
  - **RUS:** *в Польше* окончания; *на почте* vs *na poczcie/poczcie* формы.
  - **BEL:** *у Польшчы*; *h/ch* в основах на письме при произнесении.

### S4 — Dopełniacz направления/отсутствия/меры

- **Почему здесь:** *Idę do sklepu / do domu*, *nie ma…*, *u lekarza*, *kilogram sera* — нельзя жить в Польше без D, но полная «страшилка родительного» губит мотивацию, поэтому сначала **высокочастотные рамки**.
- **Уже умеет:** Loc места; Acc объекта.
- **Отложено:** Полные парадигмы D всех классов; D после всех отрицаний (частично S5); D при 5+ как отдельный mastery (углубление A2); редкие предлоги.
- **L1-ошибки:**
  - **UKR:** *додому* как неизм. → путаница с *do domu*; *з роботи* окончания.
  - **RUS:** *домой / в магазин* → *\*do sklep*, *\*w sklep*.
  - **BEL:** *дахаты / у краму* → те же предложные кальки.

### S5 — Dopełniacz после negacji + rekcja глаголов

- **Почему здесь:** После того как Acc объекта стабилизирован, вводится **переключение Acc→Gen при *nie*** и первые глаголы с D (*słuchać muzyki*). Это главный «шок» для тех, кто думал, что Acc уже закрыт.
- **Уже умеет:** Acc объекта; *nie* + V; *nie ma* + D.
- **Отложено:** Полный список rekcja; спорные/вариативные зоны без пометы; аспектуальный выбор при отрицании (аспектный путь B1).
- **L1-ошибки:**
  - **UKR:** Частичный перенос genitive of negation → и under-, и overuse.
  - **RUS:** Уверенность «как в русском» → *\*nie widziałem tę gazetę* всё равно часто.
  - **BEL:** Аналогично UKR; смешение с *няма*-конструкциями.

### S6 — Narzędnik

- **Почему здесь:** Профессия/роль (*jestem inżynierem*), транспорт (*autobusem*), *interesować się* — частотны; в A1 списке narzędnik есть. Ставится **после** Nom/Acc/Loc/Gen, чтобы контраст *jest miły* (Adj Nom) vs *jest nauczycielem* (N Narz) был осознанным.
- **Уже умеет:** Nom предикатив свойства; базовые предлоги.
- **Отложено:** Все значения Narz; тонкая стилистика; полные чередования.
- **L1-ошибки:**
  - **UKR:** *\*On jest nauczyciel*; *їхати на автобусі* вместо *autobusem*.
  - **RUS:** Сильнейший fossil *\*On jest lekarz*; *на поезде*.
  - **BEL:** То же + предложные кальки.

### S7 — Wołacz

- **Почему здесь:** Регистр и обращение дороже «ещё одной колонки окончаний» (`PED-010`, `PED-001`). В **официальной Liście A1 wołacz как раздел функций не выделен** (появляется явно на A2), поэтому продукт: **A1 = формулы** (*Panie…, Aniu, proszę pana*), **A2 = продуктивные формы**.
- **Уже умеет:** *pan/pani* + 3 л.; базовые имена.
- **Отложено:** Редкие Voc; спорные формы фамилий; полный список чередований Voc.
- **L1-ошибки:**
  - **UKR:** Ложная полная переносимость кличного → неверные польские основы (*\*Panie doktor*).
  - **RUS:** Nom вместо Voc (*\*Anna, chodź* в учебной норме обращения).
  - **BEL:** Нестабильный Voc → смесь Nom/Voc.

### S8 — Контраст направления и места (*na/w + B/Msc*)

- **Почему здесь:** После того как Acc и Loc по отдельности живы, нужен явный minimal pair: *idę na pocztę* vs *jestem na poczcie*.
- **Уже умеет:** Acc, Loc, *do + D*.
- **Отложено:** Полная лексикография *w/na* для всех существительных.
- **L1-ошибки:** Все три L1 путают падеж при том же предлоге; профили *w/na* различаются (особенно топонимы).

### S9 — Celownik

- **Почему здесь:** В zał. 1 **celownik как функция в списке A1 не развёрнут** так, как на A2; при этом формулы *dziękuję*, *mi się podoba* нужны раньше. Решение: **формулы с A1**, системный Dat на **A2**, когда клитики *mi/ci* и парадигмы не конкурируют с Gen/Loc перегрузкой.
- **Уже умеет:** Acc/Gen/Instr/Loc в быту; вежливые формулы.
- **Отложено:** Редкая rekcja только Dat; полные ударяемые формы без нужды.
- **L1-ошибки:**
  - **UKR:** Dat жив → неверные окончания / *\*dla mnie podoba się*.
  - **RUS:** *мне нравится* → порядок и *się*.
  - **BEL:** *мне падабаецца* → кальки с *dla*.

### S10 — Семь падежей + męskoosobowy (A2)

- **Почему здесь:** A2 список прямо требует męskoosobowe/niemęskoosobowe и wołacz; пора собрать спираль.
- **Уже умеет:** Функции S1–S9 в ограниченном лексиконе.
- **Отложено:** Полный контроль liczebników męskoosobowych (B1), стилистика B2.
- **L1-ошибки:** *\*te studenci byli / były* во всех трёх L1 по-разному, но категория новая для школьного сознания всех трёх (`PED-005`).

### S11–S12 — B1/B2 спираль

- **B1:** падеж × числительные; *który*+падеж; расширение rekcja; трудные N (*ręka, imię, muzeum*).
- **B2:** падеж в пассиве/безличных и причастных конструкциях; информационная структура не отменяет падеж.
- **Отложено за пределы B2:** полный C1-синтаксис падежных идиом.

## 3. Сравнение с альтернативами и обоснование компромисса

### 3.1 Альтернатива A — «традиционный учебниковый» порядок

Типичный (обобщённый) порядок многих JPJO-курсов:

**Nom → Acc → Gen → Loc → Instr → Dat → Voc**  
(иногда Loc раньше Gen; Voc в конце или «по дороге» в диалогах).

| Плюсы | Минусы для PolishApp |
|---|---|
| Привычен преподавателям; хорошо ложится на таблицы | Gen слишком рано как «большая парадигма» бьёт по мотивации |
| Близок к логике «от прямого объекта к косвенным» | Voc / регистр часто опаздывают относительно жизни в Польше |
| Легко сверять с оглавлениями | Риск клонирования учебника (`CNT-009`) |

**Оценка:** хорошая академическая база, но слабо учитывает L1-ловушки *nie + Gen*, *do + D* vs *w + Acc* и ранний регистр.

### 3.2 Альтернатива B — «частотность / коммуникативная необходимость»

Порядок по нужде быта мигранта / Katalog A (качественно, **без** выдуманных корпусных %):

**Nom → Acc → Loc (*w/na*) → Gen (*do, nie ma*) → Instr (роль/транспорт) → Voc/reguła pan → Dat → остальное.**

| Плюсы | Минусы |
|---|---|
| Быстрый выход в магазины, транспорт, жильё, urzęd-формулы | Может недодать системность парадигм |
| Совпадает с болями P-OLENA/P-VIKTOR | Нужна жёсткая дисциплина «функция, не фразы-глюки» |
| Voc/reguła раньше | Расхождение с привычкой учителей «сначала весь Gen» |

**Оценка:** ближе к продукту, но одна «фразовая» крайность нарушит `PED-001`.

### 3.3 Компромисс PolishApp (выбранный)

Берём **скелет альтернативы B** (коммуникативная необходимость), но:

1. Встраиваем **явные стадии контраста** (S5 Acc↔Gen при *nie*; S8 направление↔место), как в сильных учебниках.
2. **Voc формульно с A1**, системно с A2 — чтобы удовлетворить и жизнь, и Listę A2.
3. **Dat системно на A2**, не раздувая A1, при сохранении формул.
4. Полные трудные парадигмы и męskoosobowy×liczebniki — **спираль A2→B1**, не «всё в первой главе Gen».
5. Покрытие сверяем с zał. 1 как **чеклистом**, не как порядком глав.

Итог: не клон учебника и не чистый phrasebook.

## 4. Отдельный путь аспекта

> **Явно:** аспект **не** считается «уже освоенным», потому что он есть в UKR / RUS / BEL. Сходство инвентаря вида ≠ тождество пар, приставок, сочетаемости с будущим, императивом и отрицанием.

### Стадия A — Лексическое знакомство (A1) · `GR-ASP-LEX-01`

- **Содержание:** Пометы *dk/ndk* в словаре; несколько частотных пар в input (*robić/zrobić, kupować/kupić, czytać/przeczytać*).
- **Можно:** Узнать, что глагол «парный»; воспроизвести заученную фразу.
- **Нельзя выдавать за mastery:** Выбор вида в новом контексте; правила будущего.
- **Нормативная опора:** zał. 1 A1: аспект *wprowadzany leksykalnie* — **High**.

### Стадия B — Первый сознательный контраст (A2) · `GR-ASP-CON-01`

- **Содержание:** Минимальные пары в понятном контексте (процесс/фон vs целое событие), преимущественно прошедшее.
- **Ожидаемые ошибки L1:** Уверенный выбор «как дома» → неверная польская лексема; *\*wczoraj kupowałem telefon* без контекста длительности как замена *kupiłem*.
- **Evidence:** `pair_choice`, не только перевод.

### Стадия C — Выбор в прошедшем (A2→B1) · `GR-ASP-PST-01`

- **Содержание:** Нарратив: *gdy + ndk, dk-событие*; итератив постепенно.
- **Отложено:** Тонкие интерпретации (контив, прерванность) до B1–B2.
- **L1:** Не переносить школьные лозунги L1 о «совершенности».

### Стадия D — Будущее (A2→B1) · `GR-ASP-FUT-01`

- **Содержание:** *będę pisać / będę pisał(a)* vs *napiszę*; жёсткий запрет *\*będę napisać / \*będę zrobić*.
- **Почему отдельно:** Это самый диагностичный fossil у RUS и частый у UKR/BEL.
- **Evidence:** `pair_choice` + `disc_repair`.

### Стадия E — Императив (B1) · `GR-ASP-IMP-01`

- **Содержание:** *pisz* vs *napisz*; инструкции vs разовое требование.
- **Связь:** С регистром (*proszę* + инф.) — не голый приказ.

### Стадия F — Отрицание (B1) · `GR-ASP-NEG-01`

- **Содержание:** *nie czytał* vs *nie przeczytał* (не делал vs не довёл до результата) — **без** абсолютного правила «при *nie* всегда ndk».
- **Пометка:** Детали исключений — Medium / REQUIRES VERIFICATION по справочной грамматике при написании урока.

### Стадия G — Приставки (B1→B2) · `GR-ASP-PREF-01`, `GR-WF-PREF-01`

- **Содержание:** Приставка как значение ± вид; сеть *z-/wy-/prze-/za-…*; движение `GR-MOT-PREF-01`.
- **Запрет:** «Приставка = совершенный вид» как абсолют.

### Стадия H — Продуктивный контроль (B1–B2) · `GR-ASP-CTRL-01`

- **Содержание:** Свободный рассказ/письмо с выбором вида; экзаменационные closed items B1+.
- **Критерий честности:** Ошибки вида у «бегло говорящего» P-VIKTOR всё ещё возможны — продукт чинит их точечно, не объявляет «вид закрыт на A2».

### Сводная лента аспекта

```text
A1  LEX пары в словаре
A2  CONTRAST → PAST choice → FUT choice (база)
B1  PAST/FUT укрепление → IMP → NEG → PREFIX
B2  CTRL в нарративе/стиле + связь с причастиями/пассивом
```

## 5. Что сознательно не утверждаем

1. Не утверждаем корпусные проценты падежей без источника.
2. Не утверждаем, что порядок стадией = порядок модулей госэкзамена (у экзамена нет «главы Gen»).
