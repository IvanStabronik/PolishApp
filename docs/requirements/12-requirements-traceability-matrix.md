## 12.7 Контроль качества пакета (2026-09-04)

| Проверка | Результат |
| --- | --- |
| Противоречия | Сняты явно: пороги A1/A2 vs B1/B2; stały pobyt vs rezydent UE vs obywatelstwo; цель A1–B2 vs порядок вертикалей; UI vs L1 |
| Трассировка | Каждая BUS-строка доходит до приёмки |
| Нетестируемые формулировки | Отклонены на этапе написания («удобный», «качественный AI», «эффективное обучение» без метрики) |
| Дубли | Слоистые повторы (PRN / PED / FUN) сохранены намеренно; конфликтующих норм нет |
| Функции без работы | Админ/автор покрыты USR-014/015 и BUS-006 |
| Generic language-app | Отсекают PRN-001 и каталог XT |
| Польская специфика | Раздел 12.3 |
| AI как судья | Запрещён BUS-010, PED-023, ASM-010, CNT-010, FUN-066 |
| Target vs фазирование | Документ 10 |
