## Почему Critical/Core могут превышать половину

После сужения Critical только к закону/безопасности/непроверенному контенту/ложному уровню/потере данных/утрате польской системности, доля Critical снижена. Core остаётся широким, потому что целевое состояние — полная A1–B2-платформа первой аудитории: многие Mandatory-требования всё ещё Core по поставке, не Critical по риску.
