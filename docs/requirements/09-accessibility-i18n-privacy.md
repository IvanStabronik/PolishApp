# 09. Доступность, локализация и privacy

Первая аудитория живёт в Польше и ЕС. Польский — объект изучения, не обязательный язык интерфейса на входе. Голос и письменные работы — чувствительные учебные данные.

---

## 9.1 Accessibility

### ACC-001 — Критический путь доступен с клавиатуры и вспомогательных технологий

- **Формулировка:** Регистрация, placement, теория, закрытое упражнение, обратная связь, прогресс, экспорт/удаление выполнимы с клавиатуры. Интерактивные элементы имеют доступное имя. Цель — соответствие WCAG 2.2 уровня AA на критическом пути.
- **Причина:** Взрослая аудитория включает нарушения зрения и моторики; экзамен тоже имеет adaptations, продукт не должен быть хуже в базовом чтении.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Сценарии критического пути проходятся без мыши; автоматическая проверка a11y на этих экранах не содержит нарушений уровня A/AA, которые блокируют задачу; ручная проверка screen reader на теории и упражнении выбора.
- **Зависимости:** FUN-230, PRN-012
- **Риски:** Канвас-игра окончаний без имени.
- **Статус:** Proposed
- **Источник:** WCAG 2.2 AA; бриф
- **Проверка:** automated test, manual test

### ACC-002 — Фокус и порядок

- **Формулировка:** Порядок фокуса совпадает с учебным порядком стимул → ответ → обратная связь. Модалки ловят фокус и возвращают его.
- **Причина:** Иначе screen reader объявляет ключ до вопроса или теряет ошибку.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:** Ручной сценарий на одном закрытом пункте.
- **Зависимости:** ACC-001, FUN-062
- **Риски:** Тост вне живой области.
- **Статус:** Proposed
- **Источник:** WCAG 2.2
- **Проверка:** manual test

### ACC-003 — Контраст и не-единственность цвета

- **Формулировка:** Верно/неверно не кодируется только цветом: есть текст или иконка с именем. Контраст текста соответствует AA.
- **Причина:** Контрпримеры и ошибки падежа должны читаться.
- **Основная персона:** P-VIKTOR
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:** Скриншот без цвета всё ещё различает правильную и неправильную форму.
- **Зависимости:** FUN-051, CNT-018
- **Риски:** Красный/зелёный как единственный сигнал.
- **Статус:** Proposed
- **Источник:** WCAG 2.2
- **Проверка:** manual test

### ACC-004 — Субтитры и текст аудирования

- **Формулировка:** Учебное аудио, которое не является оцениваемым listening, имеет текст/субтитры. Оцениваемый listening по умолчанию **без** субтитров во время попытки; после попытки скрипт доступен. Есть исключение accessibility: учащийся с стойким нарушением слуха может включить постоянные субтитры — это помечает свидетельство `accommodation` и не считается тем же конструктом, что exam listening.
- **Причина:** Честность конструкта слуха vs доступность.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V2
- **Критерии приёмки:** Два режима документированы; exam-mode не включает субтитры без флага accommodation.
- **Зависимости:** FUN-110, ASM-015, FUN-160
- **Риски:** Субтитры на «экзамене» = чтение, не слух.
- **Статус:** Proposed
- **Источник:** WCAG + конструкт экзамена
- **Проверка:** manual test, content review

### ACC-005 — Парадигмы и таблицы

- **Формулировка:** Таблицы склонения имеют заголовки строк/столбцов (падеж, число, род). Они не публикуются как изображение без текстовой альтернативы.
- **Причина:** Польский без таблицы падежей недоступен, но картинка-таблица слепа.
- **Основная персона:** P-DARIA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:** Review отклоняет парадигму-скриншот без текста.
- **Зависимости:** FUN-102
- **Риски:** PNG из учебника.
- **Статус:** Proposed
- **Источник:** WCAG 1.3.1
- **Проверка:** manual test, content review

### ACC-006 — Время и запись речи

- **Формулировка:** Учебные (не exam) сессии не уничтожают ответ только из-за истечения невидимого таймера. Exam-таймер виден и предупреждает заранее. Запись речи имеет видимый индикатор и кнопку стоп.
- **Причина:** Тревога и моторные особенности.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V2
- **Критерии приёмки:** Нет скрытого автосабмита учебного пункта; exam предупреждает за ≥60 с до конца модуля (`ASSUMPTION`).
- **Зависимости:** FUN-130, ASM-014
- **Риски:** Исчезнувший ответ.
- **Статус:** Proposed
- **Источник:** WCAG 2.2.1
- **Проверка:** manual test

### ACC-007 — Понятный язык UI

- **Формулировка:** Тексты интерфейса на L1 используют короткие формулировки уровня A2 метаязыка. Учебный польский может быть сложнее — это объект, не UI.
- **Причина:** Барьер входа.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:**
  1. Qualitative user research criterion: ≥5 участников первой аудитории (UKR и/или RUS L1, взрослые в Польше) независимо проходят регистрацию и первый экран placement.
  2. Успех: ≥4 из 5 завершают без помощи модератора и без внешнего словаря для UI-строк.
  3. Каждый провал фиксируется с цитатой непонятной строки.
- **Зависимости:** I18N-001, PRN-012
- **Риски:** Канцелярит в переводах UI.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS`; `REQUIRES USER VALIDATION`
- **Проверка:** user research

## 9.2 Локализация

### I18N-001 — Языки интерфейса первой аудитории

- **Формулировка:** Критический путь доступен на русском, украинском и польском (рабочее решение редакции 2). Белорусский L1 получает отдельные заметки и банк ошибок независимо от языка UI (`I18N-006`). Белорусский UI **не обязателен** в первой публичной версии. Английский UI — Later.
- **Причина:** Нельзя учить A1, требуя B1 польского уже на кнопке «начать».
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Критический путь проходит на RUS, UKR и PL; переключение языка UI не меняет объектный польский в упражнениях; все системные ошибки критического пути переведены на эти три языка.
- **Зависимости:** PRN-012, FUN-010
- **Риски:** Только английский UI «на время».
- **Статус:** Proposed
- **Источник:** Бриф (первая аудитория); рабочее решение UI — `ASSUMPTION` / `PRODUCT ANALYSIS` (зафиксировано в ред. 2)
- **Проверка:** manual test, linguistic review

### I18N-002 — L1 в учебных материалах

- **Формулировка:** Глоссы, теория и объяснения ошибок хранятся отдельно по L1. Недопустимо считать русский перевод достаточным украинским текстом.
- **Причина:** PED-014.
- **Основная персона:** P-NATALLIA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Отсутствующий перевод L1 виден как пробел покрытия, не как молчаливый fallback на другой славянский язык, кроме явного выбора пользователя.
- **Зависимости:** FUN-052, CNT-012
- **Риски:** Fallback RU для UKR без спроса.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** automated test, linguistic review

### I18N-003 — Польский как объектный язык

- **Формулировка:** Стимулы упражнений, ключи и примеры остаются на польском. UI-локаль не «переводит» *w sklepie* в упражнении.
- **Причина:** Иначе продукт учит переводу, не польскому.
- **Основная персона:** P-AUTHOR
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Смена UI на UKR оставляет польские формы в пункте нетронутыми.
- **Зависимости:** PRN-001, FUN-050
- **Риски:** Автоперевод банка пунктов.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** automated test

### I18N-004 — Локаль дат и чисел в UI

- **Формулировка:** Даты и числа UI следуют локали интерфейса. Учебные польские даты и деньги в заданиях следуют польским конвенциям и являются частью конструкта.
- **Причина:** *15,50 zł* и порядок даты — учебный факт, не баг i18n.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:** Review различает UI-дату и учебную дату; автозамена учебной даты запрещена.
- **Зависимости:** PED-007
- **Риски:** «Починить» 15.03 на 03/15.
- **Статус:** Proposed
- **Источник:** `ASSUMPTION`
- **Проверка:** manual test, linguistic review

### I18N-005 — Направление письма

- **Формулировка:** RTL-языки не входят в первую очередь. Интерфейс LTR.
- **Причина:** Первая аудитория не требует RTL; не раздувать scope.
- **Основная персона:** P-ADMIN
- **Приоритет:** Later
- **Target necessity:** Optional
- **Delivery stage:** Later
- **Критерии приёмки:** Нет требования RTL в Critical/Core.
- **Зависимости:** BUS-009
- **Риски:** Преждевременный RTL.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** content review

### I18N-006 — Разделение UI-локали и L1 методики

- **Формулировка:** Учащийся может читать UI по-русски и иметь L1=украинский (или наоборот). Методические заметки идут от L1, не от UI.
- **Причина:** Белорусы и украинцы часто живут на русском UI.
- **Основная персона:** P-NATALLIA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Два независимых поля; смена UI не переписывает L1.
- **Зависимости:** FUN-010, I18N-001
- **Риски:** Смена языка меню меняет банк ошибок.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` (`ASSUMPTION`)
- **Проверка:** automated test

## 9.3 Безопасность и privacy

### SEC-001 — GDPR как рамка первой аудитории

- **Формулировка:** Обработка персональных данных учащихся в ЕС/ЕЭЗ соответствует GDPR: правовое основание, минимизация, доступ, исправление, экспорт, удаление, ограничение. Контролёр — юридическое лицо продукта (`DEC-007`).
- **Причина:** Пользователи живут в Польше.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Есть тексты privacy/consents до сбора; экспорт и удаление работают (`FUN-210`, `FUN-211`).
- **Зависимости:** FUN-210, FUN-211, DEC-007
- **Риски:** Сбор «на будущее».
- **Статус:** Proposed
- **Источник:** GDPR
- **Проверка:** manual test, content review

### SEC-002 — Согласия и прозрачность целей

- **Формулировка:** До сбора данных доступны условия и privacy. Обязательны: принятие условий/privacy (где применимо) и подтверждение 18+. Отдельно (не pre-ticked): разрешение на использование микрофона; опциональная аналитика; opt-in на обучение внешних моделей / вторичное использование (дефолт off, `FUN-182`). **Consent не утверждается как единственное правовое основание** хранения голоса или иных данных: для каждой цели обработки контролёр определяет и документирует основание (consent / contract / legitimate interest и т.д.); финальную схему проверяет специалист по GDPR до публичного запуска. Этот документ — не юридическое заключение.
- **Причина:** Голос и модели — не то же, что аккаунт; GDPR требует законности цели, не только галочки.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:**
  1. Микрофон включается только явным действием пользователя.
  2. Отказ от опциональной аналитики не блокирует учёбу.
  3. В privacy есть таблица «цель → категории данных → основание → срок» (хотя бы draft до запуска).
  4. Нет утверждения «согласие = единственное основание для всего».
- **Зависимости:** FUN-001, FUN-130, FUN-182, SEC-001, DEC-007
- **Риски:** Один общий «согласен со всем».
- **Статус:** Proposed
- **Источник:** GDPR; `REQUIRES USER VALIDATION` / юрист
- **Проверка:** automated test, manual test, content review

### SEC-003 — Защита при передаче

- **Формулировка:** Персональные данные и учебные ответы передаются только по защищённому каналу (TLS). Не задаётся конкретный провайдер.
- **Причина:** Пароли, тексты, голос.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Публичный HTTP без редиректа на защищённый канал на критическом пути недопустим.
- **Зависимости:** NFR-001
- **Риски:** Учебный HTTP «на время».
- **Статус:** Proposed
- **Источник:** Общепринятая практика; GDPR security
- **Проверка:** manual test

### SEC-004 — Разграничение доступа

- **Формулировка:** Учащийся видит только свои работы и голос. Автор/reviewer не видят персональные работы без роли оценщика. Админ-доступ к голосу журналируется.
- **Причина:** Сосед по общежитию не должен открыть чужой e-mail в urząd.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Горизонтальный доступ к чужому attempt id возвращает отказ; тест на IDOR обязателен (без эксплойта в открытом виде — как защитный тест «чужой id недоступен»).
- **Зависимости:** FUN-003, FUN-193
- **Риски:** Предсказуемые URL работ.
- **Статус:** Proposed
- **Источник:** GDPR; практика безопасности
- **Проверка:** automated test

### SEC-005 — Голосовые данные

- **Формулировка:** Микрофон включается только явным действием. Запись **не хранится** до явной отправки пользователем (рабочее решение редакции 2: серверное хранение голоса **выключено** до отдельного privacy/assessment design — `DEC-005`). Если хранение позже включат: для каждой цели документируется правовое основание; сроки ограничены; обучение внешних моделей и вторичное использование — только отдельный добровольный opt-in; голос не используется для биометрической идентификации. Финальную схему проверяет специалист по GDPR до публичного запуска. Документ не является юридическим заключением.
- **Причина:** Особая чувствительность; нельзя подменять legal basis одной галочкой consent.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V2
- **Критерии приёмки:**
  1. Нет фоновой записи.
  2. До включения серверного хранения сданная речь либо не уходит на сервер, либо отклоняется с понятным сообщением.
  3. После включения хранения: удаление аккаунта удаляет голос; логи без аудиопотока; таблица целей/оснований существует.
- **Зависимости:** FUN-130, FUN-182, NFR-007, DEC-005, SEC-002
- **Риски:** «Улучшим ASR на ваших файлах» в ToS.
- **Статус:** Proposed
- **Источник:** GDPR; `ASSUMPTION` / рабочее решение DEC-005; `REQUIRES USER VALIDATION` юристом
- **Проверка:** manual test, automated test

### SEC-006 — Сроки

- **Формулировка:** Рабочие допущения до утверждения юриста: экспорт — не более 30 дней; удаление аккаунта — не более 30 дней в продукте; голос неуспешной/несданной тренировки — не более 90 дней после оценки или отказа; платежные факты — сколько требует бухгалтерский закон юрисдикции контролёра. Точные сроки может сдвинуть `DEC-007`.
- **Причина:** Не хранить голос вечно.
- **Основная персона:** P-ADMIN
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Сроки опубликованы в privacy; джоба/процедура истечения существует до запуска голоса.
- **Зависимости:** FUN-210, FUN-211, NFR-015
- **Риски:** Вечный архив «вдруг пригодится».
- **Статус:** Proposed
- **Источник:** `ASSUMPTION`; GDPR storage limitation
- **Проверка:** manual test

### SEC-007 — Обработчики

- **Формулировка:** Список обработчиков персональных данных (почта, оплата, хостинг, опциональный AI) публичен в privacy. Новый обработчик не подключается молча к голосу и письму.
- **Причина:** Маленькая команда легко «подключит удобный API».
- **Основная персона:** P-ADMIN
- **Приоритет:** Core
- **Target necessity:** Important
- **Delivery stage:** V1
- **Критерии приёмки:** Чеклист запуска: список обработчиков актуален.
- **Зависимости:** NFR-004, DEC-007
- **Риски:** Теневой AI-vendor.
- **Статус:** Proposed
- **Источник:** GDPR art. 28
- **Проверка:** content review, manual test

### SEC-008 — Запрет скрытого обучения моделей на пользователях

- **Формулировка:** По умолчанию тексты и голос учащихся не используются для обучения моделей продукта или третьих лиц. Изменение только через явный opt-in.
- **Причина:** FUN-182.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Дефолт off; отсутствие согласия = нет использования.
- **Зависимости:** FUN-182
- **Риски:** Настройка vendor «train on my data» включена.
- **Статус:** Proposed
- **Источник:** GDPR; решение продукта — `PRODUCT ANALYSIS`
- **Проверка:** manual test

### SEC-009 — Только взрослые в первой очереди

- **Формулировка:** Продукт первой очереди не предназначен лицам младше 18 лет. Нет детского профиля, нет детского exam-mode.
- **Причина:** Иная правовая база и иная экзаменационная группа.
- **Основная персона:** P-ADMIN
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Регистрация требует 18+; нет UI «ребёнок».
- **Зависимости:** FUN-001, EXM-012, DEC-006
- **Риски:** Случайный школьный класс.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** automated test, manual test
