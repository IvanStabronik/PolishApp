# 10. Scope, вертикали и зависимости

Этот документ **не оценивает сроки** и **не делит работу на development tasks**. Он отделяет целевое состояние A1–B2 от порядка поставки.

Целевая спецификация в документах 00–09 **не сокращается**, если вертикаль 1 меньше цели. Вертикаль 1 — первый **production-grade** срез, не toy MVP.

**Редакция 2 (2026-09-04):** V0 = минимальный content-production workflow (не полноценный CMS/кабинет); exam-подготовка привязана к **фактически доступным** взрослым сессиям; syllabus A1–B2 не считается завершённым до Phase 2 curriculum matrices.

---

## 10.1 Что входит в целевое состояние

Полная web-платформа для взрослых UKR/RUS/BEL в Польше:

- измеримое освоение польских концептов A1–B2 со столпами `PED-001`–`PED-012` (**полная программа уровней — после Phase 2**, см. §10.8);
- теория, примеры, контрпримеры, L1-методики;
- набор exercise types, утверждённый в Phase 3 из каталога кандидатов `CNT-017` (не «все 52 обязательны»);
- четыре навыка на каждом уровне;
- модель прогресса с объяснимыми свидетельствами; интервальное повторение; словарь с морфологией и rekcja;
- диагностика, формирующие, промежуточные, суммативные тесты;
- подготовка к **доступным** госэкзаменам взрослой группы (на дату проверки: минимум B1/B2; C1/C2 вне учебной цели продукта) с порогами § 23; A1 — standards-aligned / future exam-compatible, не текущая exam-prep;
- workflow публикации с provenance и независимым методическим review (форма реализации — этап архитектуры);
- управление доступом к функциям (конкретная модель биллинга — `DEC-001`); экспорт/удаление; a11y критического пути; UI RUS/UKR/PL;
- аналитика без vanity как главных метрик;
- эксплуатация без обязательного LLM в базовом учебном пути.

## 10.3 Принцип вертикали

Вертикаль закончена, только если одновременно поставлены:

1. опубликованный оригинальный контент с provenance и независимым review;
2. упражнения и обратная связь на этот контент;
3. сохранённый и объяснимый прогресс учащегося;
4. критический путь на телефоне и на UI-языках вертикали;
5. возможность экспорта/удаления уже собранных данных (с первой пользовательской вертикали).

«Движок без уроков» и «уроки без исполняемых упражнений и прогресса» вертикалью не считаются.

## 10.4 Порядок вертикалей (рабочее допущение)

Порядок — `ASSUMPTION` / `PRODUCT ANALYSIS` для планирования. Владелец может переставить вертикали, но не вычеркнуть Mandatory-столпы из §10.1.

### Вертикаль 0 — Минимальный content-production workflow

**Зачем:** нельзя учить на непроверенном оригинале.

**Результат (не технология):** можно создать учебную единицу, зафиксировать автора/reviewer/версию/источники, провести независимый review, опубликовать или отклонить. Self-approve запрещён.

**Не требует:** полноценного authoring cabinet, выбранного CMS, admin SPA или graph database. Архитектура позже решит: structured files, scripts, CMS или UI.

**Не поставляет:** учебный путь учащегося.

**Зависит от:** CNT-002–CNT-008, CNT-020, BUS-005, BUS-010.

**Разблокирует:** публикацию контента для V1+.

### Вертикаль 1 — Первый production-grade учебный срез

**Обязательный сквозной сценарий:**

`регистрация → определение L1 и цели → один законченный учебный модуль → упражнения → обратная связь → сохранённый прогресс`.

**Зачем:** P-OLENA получает ценность без ожидания полной A1–B2.

**Также включает (минимум):** UI RUS/UKR/PL; различие трёх L1; запрет выдавать прогресс за сертификат; экспорт/удаление данных; закрытые упражнения с ключом по польским явлениям модуля (падеж/rekcja и/или орфография/регистр — по содержанию модуля); объяснение ошибки без свободной генерации как единственного источника.

**Может отложить:** полный placement, полный exam-mode, серверное хранение голоса, широкий словарь, SRS зрелого вида, человеческую итоговую оценку письма/речи.

**Нельзя отложить:** provenance опубликованного модуля; независимый review; три L1 как отдельные значения; дисклеймер «не госэкзамен».

**Зависит от:** V0.

### Вертикаль 2 — Расширение A1-навыков и диагностики

**Поставляет:** более полный A1-контент по утверждённой (или промежуточной) матрице; чтение/слух; контролируемое письмо; говорение без серверного хранения по умолчанию; внутренний суммативный/standards-aligned тест A1; фонетические perceptive типы по мере готовности.

**Не называет A1 «подготовкой к текущему госэкзамену»**, пока A1 отсутствует в актуальном расписании взрослых сессий (`EXM-001`, дата проверки в `07`).

### Вертикаль 3 — A2

Спираль падежных функций, введение аспекта и męskoosobowy, liczebniki 5+, промежуточные тесты кластеров — **после** появления Level A2 curriculum matrix (Phase 2). До матрицы — не объявлять A2 «полным».

### Вертикаль 4 — B1 + exam-mode B1 (доступный госэкзамен)

Первый внешний порог первой аудитории. Exam-mode с 50% на каждый модуль; ≥2 оригинальные сборки; ремонт слабого модуля; честная справка о праве. Итоговая оценка письма/речи — по `DEC-002` (открыто).

### Вертикаль 5 — B2 + exam-mode B2

Целевая самостоятельность; порог 60%; покрытие по B2 matrix Phase 2.

### Later — Зрелость

Item analysis; календарная справка сессий; белорусский UI (не обязателен); английский UI; богатый словарь; локальная тренировка речи; A1 exam-compatible mode **если** появится в расписании взрослых сессий.

## 10.5 Зависимости между классами требований

```text
BUS → USR / PRN
USR → FUN
PRN → режет FUN / CNT
PED → задаёт педагогический результат (не готовый syllabus)
CNT → питает FUN и ASM
ASM → определяет mastery и тесты
EXM → специализирует exam-path для доступных уровней
NFR / SEC / ACC / I18N → ограничивают все поставки
DEC → может сдвинуть способ исполнения, не отменяет Mandatory-результат
Phase 2 curriculum matrices → делают измеримым «полный уровень»
Phase 3 exercise ICE → утверждает набор XT
```

| Нельзя закрыть | Пока нет |
| --- | --- |
| V0 | CNT-020; блокировка публикации без provenance |
| V1 | сквозной сценарий §10.4; L1×3; feedback без AI-only ключа |
| V2 | PED-019 для опубликованного A1-среза; аудио для assessed listening |
| V3 | Level A2 matrix (Phase 2) + PED-004/005/007 в scope матрицы |
| V4 | EXM-003; доступность B1 в актуальном расписании; ASM-010 |
| V5 | EXM-004; Level B2 matrix; CNT-016 |
| «Целевое состояние достигнуто» | V1–V5 + Phase 2 matrices + Phase 3 утверждённый набор типов |

## 10.6 Что можно сдвигать, что нельзя

| Можно сдвинуть | Нельзя вычеркнуть из цели |
| --- | --- |
| Форма authoring UI | Provenance + независимый review |
| Полный placement в V1 | L1 и цели в V1 |
| Exam-mode | Подготовка к доступным госэкзаменам (B1/B2+) |
| Серверное хранение голоса | Явное действие микрофона; нет биометрии |
| Белорусский UI | Белорусский L1-пакет |
| Все 52 XT | Польско-специфичные обязательные группы после Phase 3 |
| AI-перефраз подсказок | Банк/утверждённые объяснения; AI не единственный судья |

## 10.7 Риски порядка

1. Раздуть V0 в «полноценную админку» и отложить учебный путь.
2. Объявить V1 toy MVP и вычеркнуть цель A1–B2.
3. Называть A1 exam-prep при отсутствии сессий для взрослых.
4. Объявить уровень «полным» без Phase 2 matrices.
5. Считать все XT обязательными до Phase 3.
6. Подменить reviewer генеративной моделью.
