# 02. Принципы продукта

Принципы режут решения. Если функция не проходит принцип, она не входит в продукт, даже если привычна language-app рынку.

Каждый принцип связан с требованиями. Принцип сам по себе не заменяет атомарное требование.

### PRN-001 — Польский в центре, не «язык вообще»

- **Формулировка:** Функция допускается, только если можно назвать конкретное польское явление или польскую коммуникативную ситуацию, ради которых она существует.
- **Причина:** Generic streak, лиги, «5 новых слов в день» не чинят dopełniacz zaprzeczenia и не готовят к модулю *poprawność gramatyczna*.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V0
- **Критерии приёмки:** В обосновании Critical/Core функции есть отсылка к польскому явлению, экзаменационному модулю или L1-интерференции; ревью требований отклоняет формулировки без этой отсылки.
- **Зависимости:** PED-001–PED-013
- **Риски:** Скопированный backlog Duolingo.
- **Статус:** Proposed
- **Источник:** Бриф
- **Проверка:** content review

### PRN-002 — Концепт важнее урока

- **Формулировка:** Единица освоения — концепт с границами применения; урок только собирает концепты. Прохождение экрана не равно mastery.
- **Причина:** «Падежи» как один урок создают иллюзию закрытой темы; польский требует спирали.
- **Основная персона:** P-VIKTOR
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Модель прогресса хранит состояние на уровне концепта; урок может быть завершён при не-mastered концептах.
- **Зависимости:** BUS-003, FUN-040, FUN-080, ASM-005
- **Риски:** CMS как блог уроков без графа концептов.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** automated test, manual test

### PRN-003 — Спираль, не конвейер

- **Формулировка:** Одни и те же польские системы возвращаются на каждом уровне с новым контекстом, а не «проходятся» один раз.
- **Причина:** Mianownik/biernik на A1 не отменяют dopełniacz po liczebnikach и męskoosobowy на B1.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** В syllabus есть повторные концепты-потомки (например, biernik A1 и biernik po czasownikach ruchu A2/B1) с отдельными ID, связанные родительским концептом.
- **Зависимости:** PED-015, FUN-032
- **Риски:** Линейный учебник, замаскированный под приложение.
- **Статус:** Proposed
- **Источник:** CEFR spiral; бриф; практика JPJO
- **Проверка:** content review

### PRN-004 — L1 — отдельная методика, не подпись под примером

- **Формулировка:** Для UKR, RUS и BEL существуют отдельные банки ошибок, контрасты и, где нужно, разный порядок акцента. Это не один «east Slavic mode».
- **Причина:** Украинский vocative и вид ближе к польскому; русский переносит свободное ударение и другую rekcja; белорусский даёт иной *h/ch* и орфографические ожидания.
- **Основная персона:** P-NATALLIA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Три L1-пакета можно включить/выключить независимо; контент-ревью проверяет уникальность, а не перевод одного файла.
- **Зависимости:** PED-013, PED-014, CNT-012
- **Риски:** Русский комментарий, выданный за украинский.
- **Статус:** Proposed
- **Источник:** Бриф
- **Проверка:** linguistic review

### PRN-005 — Контрпример обязателен там, где правило имеет границу

- **Формулировка:** Концепт с исключением, омонимией или L1-ловушкой не публикуется без контрпримера.
- **Причина:** *uczę się polskiego* vs *uczę polskiego*; *ż* vs *rz*; *do* + D vs *w* + Miejscownik.
- **Основная персона:** P-DARIA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Publication checklist требует контрпример для концептов с тегом `boundary` или `l1-trap`.
- **Зависимости:** PED-017, CNT-018, FUN-051
- **Риски:** Полуправило, которое учащийся сверхгенерализует.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** content review

### PRN-006 — Четыре навыка не откладываются «на потом навсегда»

- **Формулировка:** Целевое состояние каждого уровня A1–B2 содержит чтение, слух, письмо и речь. Вертикаль может временно сужать навык, но не вычёркивать его из цели уровня.
- **Причина:** Постановление 2025 г. уже на A1 проверяет słuch, czytanie, pisanie, mówienie.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V2
- **Критерии приёмки:** Документ 10 может сдвинуть продуктивные навыки внутри вертикали, но `USR-010` остаётся Critical для целевого состояния.
- **Зависимости:** USR-010, PED-019, документ 10
- **Риски:** Вечная «грамматика без рта».
- **Статус:** Proposed
- **Источник:** Dz.U. 2025 poz. 217
- **Проверка:** content review

### PRN-007 — Закрытый ключ там, где форма однозначна; человек там, где смысл

- **Формулировка:** Падеж, орфография, аспект в закрытом контексте оцениваются ключом. Свободное письмо и речь для mastery и exam-mode оцениваются рубрикой человека или откладываются, но не отдаются модели как единственному судье.
- **Причина:** LLM уверенно принимает несуществующую форму *w sklepu* или пропускает ошибку регистра.
- **Основная персона:** P-REVIEWER
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V0
- **Критерии приёмки:** Нет пути, в котором единственный score письма/речи для exam-mode ставит нечеловек-модель; см. `ASM-010`.
- **Зависимости:** BUS-010, ASM-009, ASM-010, DEC-002
- **Риски:** Дешёвая автопроверка продуктивных навыков = ложный B1.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** manual test

### PRN-008 — Оригинал или ничего

- **Формулировка:** Можно изучать стандарты и сравнивать учебники. Нельзя воспроизводить их сюжет, последовательность глав, персонажей и наборы заданий. AI-перефраз не считается оригиналом.
- **Причина:** Правовой риск и педагогическая вторичность.
- **Основная персона:** P-AUTHOR
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V0
- **Критерии приёмки:** Provenance заполнен; reviewer подтверждает неклонность; официальные бланки отсутствуют.
- **Зависимости:** CNT-001, CNT-009, CNT-010, CNT-011
- **Риски:** «Временный» пересказ Hurra!!! / Polski krok po kroku.
- **Статус:** Proposed
- **Источник:** Бриф
- **Проверка:** content review

### PRN-009 — Честность экзаменов и права

- **Формулировка:** Продукт готовит к экзамену, не притворяется экзаменом и не даёт юридических гарантий по pobyt/obywatelstwo.
- **Причина:** Доверие первой аудитории легко сжечь одним ложным claim.
- **Основная персона:** P-OLENA
- **Приоритет:** Critical
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Экран exam-mode и юридический справочник содержат обязательные дисклеймеры из `EXM-007` и `EXM-013`.
- **Зависимости:** BUS-008, EXM-007
- **Риски:** Реклама «сдадите B1 с нами».
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` (официальные акты)
- **Проверка:** content review

### PRN-010 — Бережливая автоматизация

- **Формулировка:** Автоматизация допустима, если она детерминирована, проверяема и дешева в эксплуатации. Генерация на каждый клик учащегося запрещена как зависимость базового пути.
- **Причина:** 15 часов основателя и неизвестный бюджет.
- **Основная персона:** P-ADMIN
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V0
- **Критерии приёмки:** Базовый путь работает при выключенных AI-флагах; есть потолок стоимости вспомогательных вызовов — `NFR-004`.
- **Зависимости:** BUS-006, NFR-004
- **Риски:** «Умные подсказки» как скрытый счетчик токенов.
- **Статус:** Proposed
- **Источник:** Бриф
- **Проверка:** manual test

### PRN-011 — Доказательства важнее украшений

- **Формулировка:** Метрика продукта допустима, если она связана с освоением, удержанием слабых концептов, качеством контента или доходимостью до порога модуля. Очки, лиги и streak не могут быть главной метрикой.
- **Причина:** Vanity metrics прячут fossilization.
- **Основная персона:** P-ADMIN
- **Приоритет:** Advanced
- **Target necessity:** Important
- **Delivery stage:** V2
- **Критерии приёмки:** Админ-дашборд по умолчанию открывает педагогические метрики `FUN-181`.
- **Зависимости:** FUN-180, FUN-181
- **Риски:** Оптимизация «дневной активности» вместо mastery.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** manual test

### PRN-012 — Доступность и язык интерфейса — часть обучения, не косметика

- **Формулировка:** Первая аудитория учит польский, но живёт на украинском, русском или белорусском. Интерфейс и a11y не должны требовать уже готового B1, чтобы начать A1.
- **Причина:** Экран «заполните formularz» на польском без глосс отсекает P-OLENA.
- **Основная персона:** P-OLENA
- **Приоритет:** Core
- **Target necessity:** Mandatory
- **Delivery stage:** V1
- **Критерии приёмки:** Критический путь регистрации, placement и урока доступен на UI-языках `I18N-001`; учебный польский при этом остаётся объектом изучения.
- **Зависимости:** I18N-001, I18N-003, ACC-001
- **Риски:** «Погружение с первого экрана» как барьер, не метод.
- **Статус:** Proposed
- **Источник:** `PRODUCT ANALYSIS` / `REQUIRES USER VALIDATION`
- **Проверка:** manual test, user research

## Принципы, которые продукт отвергает

| Отвергнутый паттерн | Почему не подходит польскому |
| --- | --- |
| Translation-only drills | Не учит rekcja и порядку слов, закрепляет кальку |
| «Слово дня» без рамки | *sklep* без местника и предлога бесполезен |
| Лиги и сердца как ядро | Не измеряют męskoosobowy |
| Бесконечный чат с ботом | Неконтролируемые формы, стоимость, ложная беглость |
| Один объясняющий язык для всех славян | Стирает UKR/RUS/BEL |
| Клон последовательности популярного учебника | Нарушает CNT и не создаёт актив |
| AI как экзаменатор письма | Невалидная оценка, риск ложного mastery |
