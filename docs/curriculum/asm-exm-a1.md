# ASM / EXM уровень A1

**Статус:** A1 semantic reference — candidate for human review.
**Определения:** [`entity-definitions.md`](entity-definitions.md).
**Связь со сценариями:** [`scenario-inventory.md`](scenario-inventory.md).
**Миграция:** [`functional-migration-a1.md`](functional-migration-a1.md) (в частности бывшие FN-A1-031, FN-A1-035).

`ASM-*` — внутренняя оценка / учебный жанр продукта.
`EXM-*` — ориентир госэкзамена. **Взрослая сессия A1 в расписании 2026 не объявлена** (`session_availability=not_announced`); `standard_status=current`. Не помечать A1 как `historical`.

Проверка источников (2026-09-05): [terminy 2026](https://certyfikatpolski.pl/terminy-sesji-egzaminacyjnych-w-2026-roku/), [struktura](https://certyfikatpolski.pl/o-egzaminie/struktura-egzaminu/), Dz.U. 2025 poz. 217.

## 1. ASM-A1 — задания оценивания и метаучебные действия

### ASM-A1-WRITE-SELF-01 — Письмо о себе (3–5 предложений)
- **Тип:** учебный письменный жанр / внутренняя оценка
- **Откуда мигрировано:** FN-A1-035
- **Сценарий-носитель:** SCN-A1-WRITE-SELF-01
- **Опирается на FN:** FN-A1-IDENTIFY-01, FN-A1-IDENTIFY-02, FN-A1-LOCATE-01, FN-A1-NARRATE-01 (optional)
- **Что измеряет:** способность письменно собрать биографические слоты в связный мини-текст, а не «умение жить в Польше» как таковое.
- **Критерий успеха (наблюдаемый):** Текст 3–5 предложений на польском; разборчив; содержит имя (или устойчивое самоназвание), место жительства/происхождения и ещё ≥1 факт (работа, язык, рутина). Допускается 1 черновик. Блок: <3 предложений; только список слов без глаголов; текст на L1.
- **Allowed support:** план из 4 пунктов; проверка орфографии после сдачи (не во время, если режим exam-like).
- **Criticality для exit A1:** Important (не Core выживания; важно для writing track).
- **Примечание:** Не объявлять госсертификатом; может готовить к будущему модулю pisanie.

### ASM-A1-FORM-FOLLOW-01 — Следование экранной / бумажной форме (przelew и аналоги)
- **Тип:** form-following / procedural literacy
- **Откуда мигрировано:** FN-A1-031 (и часть bank UX)
- **Сценарий-носитель:** SCN-A1-BANK-01
- **Опирается на FN:** FN-A1-QUANT-01, FN-A1-READ-01, FN-A1-DOCS-01 (идентификаторы)
- **Что измеряет:** умение перенести данные в поля шаблона без потери суммы/получателя/титула платежа — **не** свободный речевой акт «сделать перевод».
- **Критерий успеха:** Все обязательные поля шаблона заполнены; сумма и получатель совпадают с карточкой-заданием; учащийся подтверждает отправку в симуляции. Допускается 1 подсказка «sprawdź pole X». Блок: сумма ≠ ключ; пустой получатель; отправка до заполнения обязательных полей.
- **Allowed support:** образец заполненного поля (не всей формы); легенда терминов LEX-A1-BANK.
- **Criticality:** Important для DOM-BANK track.
- **Примечание:** Термины bank — LEX; успех сценария банка = SCN + этот ASM.

### ASM-A1-DIAG-ORAL-01 — Диагностический устный зонд A1
- **Тип:** diagnostic assessment
- **Опирается на FN:** FN-A1-IDENTIFY-01, FN-A1-GREET-01, FN-A1-REPAIR-01, FN-A1-ASK-01, FN-A1-TRANS-01 (выборка)
- **Что измеряет:** стартовый профиль пробелов по Core FN, не vanity-балл.
- **Критерий успеха процедуры:** Отчёт содержит статусы по затронутым FN/концептам и L1-риски; нет единственного процента как главного вывода.
- **Связь требованиям:** ASM-001 (пакет требований) — методическая реализация на уровне A1.
- **Criticality:** Core для onboarding продукта (процедура), не «знание языка» само по себе.

### ASM-A1-SELF-CHECK-01 — Самопроверка после сценария
- **Тип:** metacognitive checklist
- **Опирается на:** любой завершённый SCN-A1-*
- **Что измеряет:** осознание «что получилось / где нужен repair», не грамматический тест.
- **Критерий успеха:** Учащийся отмечает ≥3 пункта чеклиста (сделал / частично / не сделал) и выбирает 1 цель повтора; время ≤ 3 мин.
- **Criticality:** Extension (habit), не блокирует exit.

### ASM-A1-REG-DISC-01 — Дискриминация регистра (готовые реплики)
- **Тип:** controlled discrimination task
- **Опирается на FN:** FN-A1-REG-01, FN-A1-ADDRESS-01, FN-A1-GREET-01
- **Критерий успеха:** ≥5/6 верных выборов официальное↔неофициальное + 1 продуктивное применение.
- **Criticality:** Core evidence канал для REG-01.

## 2. EXM-A1 — экзаменационные ориентиры

> **Важно:** ниже — выравнивание со **стандартом** и структурой экзамена.
> **Сессия взрослых A1 в 2026 не объявлена.** Подготовка — future / standards-aligned слой.
> Не утверждать, что продукт «сдаёт» госэкзамен.

### EXM-A1-STRUCT-01 — Модульная структура взрослых A1
- **standard_status:** current
- **session_availability:** not_announced (снимок 2026-09-05)
- **Содержание:** Ориентиры модулей słuchanie / czytanie / pisanie / mówienie по [struktura egzaminu](https://certyfikatpolski.pl/o-egzaminie/struktura-egzaminu/) и Dz.U. 2025 poz. 217.
- **Связь с продуктом:** Карта покрытия FN/SCN → модули; без имитации «официального балла».
- **Проверенные параметры:** письменная часть — не более 120 минут; устная — не более 10 минут; порог — не менее 50% баллов отдельно за письменную и устную части. Источник: официальная таблица структуры экзамена, проверено 2026-09-05.

### EXM-A1-LISTEN-01 — Ориентир słuchanie A1
- **Назначение:** Сопоставить учебные аудирования (PHONE, касса, запись) с типами экзаменационных аудитивных заданий.
- **Связанные FN (пример):** FN-A1-PHONE-01, FN-A1-REPAIR-01, FN-A1-TIME-01, FN-A1-QUANT-01
- **session_availability:** not_announced
- **Примечание:** Внутренние listening tasks ≠ сертификат.

### EXM-A1-READ-01 — Ориентир czytanie A1
- **Назначение:** Короткие утилитарные тексты (вывески, инструкции) как подготовка к чтению A1.
- **Связанные FN:** FN-A1-READ-01
- **Связанные SCN:** SCN-A1-TICKET-01, SCN-A1-SHOP-01, SCN-A1-MED-01, SCN-A1-HOUSING-01
- **session_availability:** not_announced

### EXM-A1-WRITE-01 — Ориентир pisanie A1
- **Назначение:** Анкета + короткий связный текст о себе как мост к письменному модулю.
- **Связанные ASM:** ASM-A1-WRITE-SELF-01
- **Связанные FN / SCN:** FN-A1-FORM-01 / SCN-A1-FORM-01
- **session_availability:** not_announced
- **Примечание:** Не выдавать внутренний текст за экзаменационную работу.

### EXM-A1-SPEAK-01 — Ориентир mówienie A1
- **Назначение:** Устные сценарии IDENTIFY / TRANS / APPOINT / URZAD как покрытие говорения.
- **Связанные FN:** FN-A1-IDENTIFY-01, FN-A1-IDENTIFY-02, FN-A1-TRANS-01, FN-A1-PURPOSE-01, FN-A1-APPOINT-01, FN-A1-GREET-01
- **session_availability:** not_announced

## 3. Сводка счётчиков A1 (ASM/EXM)

| Класс | ID | Число |
| --- | --- | ---: |
| ASM | WRITE-SELF, FORM-FOLLOW, DIAG-ORAL, SELF-CHECK, REG-DISC | **5** |
| EXM | STRUCT, LISTEN, READ, WRITE, SPEAK | **5** |

Элементы, **явно перенесённые** из старых FN: WRITE-SELF (035), FORM-FOLLOW (031). Остальные ASM/EXM — каркас оценивания и экзаменационного слоя, согласованный с новой моделью сущностей.

A2–B2 ASM/EXM в этом файле **не** объявляются.
