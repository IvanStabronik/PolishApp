# Миграция A1: старые FN-A1-001…042 → FN / SCN / ASM / EXM

**База:** commit `10ed7f3`, ветка `docs/phase-2-integrity-fix`.
**Цель:** разделить смешение функций, сценариев и заданий без потери продуктового результата.
**Определения:** [`entity-definitions.md`](entity-definitions.md).
**Канон FN после миграции:** 30 IDs в `functional-inventory.md` (A1).
**Статус:** A1 candidate for review; A2–B2 не мигрированы.

Легенда **decision:**

| Код | Значение |
| --- | --- |
| `KEEP_FN` | сохранить как каноническую FN (возможно с новым ID) |
| `MERGE_FN` | объединить в уже существующую / целевую FN |
| `SPLIT` | разделить: речевое ядро → FN, контекст → SCN (и/или ASM) |
| `TO_SCN` | преобразовать в сценарий (речевые акты покрываются другими FN) |
| `TO_ASM` | перенести в задание оценивания / учебный жанр |
| `TO_EXM` | перенести в экзаменационный ориентир (если уместно) |

## Сводные итоги миграции

| Показатель | Число |
| --- | ---: |
| Старых записей `FN-A1-*` | 42 |
| Новых канонических FN | 30 |
| Созданных SCN A1 (см. scenario-inventory) | 17 |
| Элементов с явным переносом в ASM | 2 (+ связи из bank/write) |
| Элементов EXM (ориентиры, сессия not_announced) | 4 |
| Старых ID с потерей продуктового результата | **0** |

Семантические решения (обязательные):

1. Магазин / еда / билет → `SCN-*` + общая `FN-A1-TRANS-01` (не три FN).
2. Вопросы о наличии → слияние в `FN-A1-ASK-01`.
3. Просьба о бланке / недостающем документе → слияние в `FN-A1-DOCS-01`.
4. Отсутствие ребёнка + usterka → `FN-A1-REPORT-01`.
5. «Написать 3–5 предложений о себе» → `ASM-A1-WRITE-SELF-01` (+ сценарий письма).
6. Przelew по образцу → `SCN-A1-BANK-01` + `ASM-A1-FORM-FOLLOW-01`.
7. Настоящие речевые акты остаются `FN-*`.
