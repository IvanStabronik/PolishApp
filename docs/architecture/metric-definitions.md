# Metric definitions (Milestone 4)

| Key | Meaning | Interpretation limits |
| --- | --- | --- |
| `activation_invite_to_onboarding` | Invite accept → registration/onboarding cohort events | Does not measure learning quality |
| `first_lesson_started` | Lesson open events | Open ≠ complete |
| `first_exercise_submitted` | Persisted attempts | Includes formative/preview modes when present |
| `first_lesson_completed` | Lesson completion path events | Heuristic; not JPJO mastery |
| `day1_readiness` / `day7_readiness` | Return activity windows | UTC buckets; small-n noise |
| `attempts_per_learner` | Attempts / active learners | Power-user skew |
| `les_completion` | LES-* completion counts | DRAFT content included in beta |
| `review_queue_usage` | Powtórka usage | Not retention proof |
| `incorrect_rate_by_exercise` / `_by_concept` | Incorrect ÷ attempts | Low sample; not IRT |
| `feedback_rate` | Feedback ÷ active learners | Voluntary selection bias |

No advertising trackers. Admin sees aggregates only.
